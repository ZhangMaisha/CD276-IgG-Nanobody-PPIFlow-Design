This package contains continuous 0–50 ns MD analysis results for the selected CD276 nanobody and IgG antibody complexes.

Main analysis files:
- rmsd_0_50ns.xvg
- rmsd_0_50ns_xtal.xvg
- gyrate_0_50ns.xvg
- rmsf_0_50ns.xvg
- chain-specific rmsf_0_50ns_*.xvg
- sasa_0_50ns.xvg
- sasa_residue_0_50ns.xvg
- mindist_0_50ns.xvg
- contacts_0_50ns.xvg
- hbonds_0_50ns.xvg

The continuous trajectory was generated by concatenating 10 ns segments from 0 to 50 ns.
